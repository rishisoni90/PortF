01 — Overview

What Is the PDO/PDL Platform?

Ford vehicles are defined by thousands of features — options, configurations, rules, and constraints that vary across programs, markets, and trims. The PDO/PDL platform is the system that manages all of it: a rule-driven engine where business stakeholders define feature combinations, the backend enforces rule logic, and teams deploy configurations consistently across environments.

In two lines: Built a platform at Ford where teams define and validate vehicle feature rules through a UI, the Java backend enforces those rules for safety-critical systems, and everything integrates seamlessly to downstream applications — eliminating manual coordination across large-scale automotive programs.

The Challenge
  • Vehicle features span thousands of rules across programs, markets, and environments
  • No centralized platform — rules scattered across teams and systems
  • Manual validation of feature combinations, error-prone in safety-critical context
  • Stakeholders with no coding background needed to author and manage rules
  • Inconsistent integration between rule authoring and downstream vehicle programs
The Solution
  • Single rule-driven platform for dynamic feature definition, validation, and deployment
  • Java-based business logic engine handling rule conditions accurately at scale
  • Angular UI enabling non-technical stakeholders to author and manage rules directly
  • Spring Boot REST APIs connecting rule authoring to downstream applications
  • SQL Server data modeling ensuring high-performance retrieval and data integrity
