01 — Overview

What This System Does

The automation framework validates the complete wire payment lifecycle — from wire initiation using Selenium or PRAPI, through database verification, to final validation reporting. Jenkins triggers the full run every night at 7 PM with all data and secrets managed in AWS.

In two lines: Built an end-to-end wire payment test automation at Capital One that eliminated 2 weeks of manual testing — Jenkins runs the full cycle every night at 7 PM, validates DB results against the original data sheet, and emails the team results by morning.

🔌

Wire Initiation

Creates wire payments via Selenium (UI) or PRAPI (API). Channel type is read from the Excel sheet and determines the execution path.

🗄️

DB Fetch

After wire completes, queries the database for payment messages, audit trails, wire status, and all associated transaction metadata.

✅

Validation

Compares every fetched DB value against the original initiation Excel sheet. Each field generates a PASS or FAIL result.

📧

SNS Notifications

AWS SNS sends automated email alerts with pass/fail summaries to all configured recipients after every run.

📊

Extent Reports

Rich HTML test reports with step-level detail, screenshots on failure, and run history — stored permanently in S3.

🔒

Secrets Management

PRAPI credentials stored in AWS Secrets Manager — fetched after wire initiation only for API channels. Selenium runs need no secrets.

Step 1 — Initiation
Wire Creation via Selenium or PRAPI

Test loads wire parameters from an Excel sheet in S3, then initiates the wire via Selenium (browser UI) or PRAPI (programmatic API). The channel type specified in the sheet determines what happens next.

Step 1b — API Channels Only
Channel-Based Secrets Fetch

After initiation, if the channel is API-based (SBBMM, TMOBS, or WSSAPI), the matching credentials are fetched from AWS Secrets Manager. Each channel has its own client ID and secret. Selenium runs skip this entirely.

Step 2 — Data Passing
Excel-Driven Test Data

Wire parameters (amount, beneficiary, account numbers, reference codes) are passed from the input Excel sheet loaded from S3. After wire creation, the data file is preserved in S3 for later comparison.

Step 3 — DB Fetch
Fetching Wire Details from Database

Once the wire is complete, the automation queries the database for payment messages, audit trail entries, wire status records, and all associated transaction metadata. The output is written to an Excel sheet saved to S3.

Step 4 — Validation
DB Values vs. Initiation Sheet

Every field from the database is compared against the original initiation sheet. Each comparison generates PASS or FAIL. A validation summary sheet is written and stored in S3 as a permanent audit trail of the run.

Step 5 — Reporting
SNS Email + Extent HTML Reports

After validation, AWS SNS fires an email to all stakeholders with pass/fail summaries. Extent Reports generates a rich HTML report with step-by-step results and screenshots — stored permanently in S3.

03 — Infrastructure

Cloud Architecture

The entire system runs on AWS, with Jenkins as the execution engine. All state — test data, results, secrets — lives in managed AWS services.

🔒

Secrets Manager

Per-channel credentials (SBBMM, TMOBS, WSSAPI). Fetched after initiation — API channels only.

aws secretsmanager
🪣

S3 Bucket

Input data sheet, DB output sheet, validation results, and Extent HTML reports — all stored here.

aws s3
📬

SNS

Automated email notifications to stakeholders after every validation run completes.

aws sns
⚙️

Jenkins

Schedules and executes the full pipeline every night at 7 PM. Moved from local workspace to CI.

jenkins ci

06 — Evolution

Local → Cloud Migration

The framework was originally built and run locally. Moving to Jenkins and AWS made it zero-touch, team-visible, and reliably scheduled.

Before — Local
  • 🔴   Run manually — 2 weeks of testing per cycle
  • 🔴   Test data files stored locally
  • 🔴   Credentials in config files
  • 🔴   No scheduled execution
  • 🔴   Results not shared automatically
After — Jenkins + AWS
  • 🟢   Automated nightly at 7 PM — zero manual effort
  • 🟢   Data sheets centralized in S3
  • 🟢   Secrets in AWS Secrets Manager
  • 🟢   Reliable scheduled execution via Jenkins
  • 🟢   SNS email + S3 reports visible to whole team
